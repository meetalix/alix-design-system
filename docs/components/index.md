# Components

The crafted kit. **Build only from these** — every target is ≥44pt, every component is named, and each consumes semantic tokens so the system re-themes from one place. If a feature needs something not here, add it to the system rather than inventing a one-off.

Each component's full reference (props, behavior, do/don't) lives beside its code.
